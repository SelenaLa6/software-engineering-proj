# Software Engineering Project 

Champernowne's constant is an irrational decimal number formed by concatenating base-10 positive integers. (https://en.wikipedia.org/wiki/Champernowne_constant)

Given an input of a positive integer, n, this program will return the nth digit of Champernowne's constant.

Example:
input = 12
output = 1
(The 12th digit of 0.12345678910111213... is "1")
